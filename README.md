Expense Tracker
About:
This is a simple expense tracker website that helps users keep track of their daily expenses. Users can add expenses, see a list of what they’ve spent, and view the total amount.
I built this project to practice HTML, CSS, and JavaScript and to understand how basic web applications work.

Live Project:
🔗 https://nehadolas20.github.io/Expense-Tracker/

Tech Used:
HTML
CSS
JavaScript

Features:
Add expenses with amount and category
View all expenses in one place
Automatic total calculation
Clean and easy-to-use interface

How to Use:
Open the live link or download the project
Open index.html in a browser
Start adding your expenses
No setup needed.

What I Learned:
Handling user input using JavaScript
Basic DOM manipulation
Structuring a simple front-end project
